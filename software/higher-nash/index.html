Higher Nash Tools

A computational toolkit for the study of higher Nash modifications and singularities.

About the project

Higher Nash Tools is a collection of computational routines developed to assist computations involving higher-order Jacobian matrices, weighted orders, optimal matchings, minors, and Grassmannian separation.

The complete implementation is maintained in the GitHub repository .

Verified example: $E_6$

Polynomial

\[ f=x^2+y^3+z^4 \]

Blow-up configuration

Exceptional divisor: \[ x+iz=0. \]

This is the reproducible example used in the computational pipeline.

Verified computational results

Leading exponent vector
[8, 6, 4]
Higher Jacobian matrix
35 × 55
Minimum matching cost
226
Optimal column sets
66

Curves

The two curves used in the example are

\[ \gamma_1(t)= \left( it^8(-t^2-2t-1), t^6(t+1), t^4(t+1) \right), \] \[ \gamma_2(t)= \left( it^8(-t^2+2t-1), t^6(t-1), t^4(t-1) \right). \]

What has been verified

The repository tests currently verify the computational pipeline through the construction of the weighted-order matrix, minimum-cost matching, and complete enumeration of the optimal column sets.

For the example above, the verified values are

\[ e=(8,6,4), \qquad O\in\mathbb{Z}^{35\times55}, \qquad c_{\min}=226, \qquad \#\mathcal C_{\min}=66. \]

Exact symbolic minors and Grassmannian separation are not executed automatically by this webpage.
